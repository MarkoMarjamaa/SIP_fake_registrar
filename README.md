# SIP_fake_registrar
With this you are able to create accounts in SIP software that need a registrar, even if you are only making P2P calls.

When you are only making p2p calls, you don't need to register to "phone book", it's always from IP to another IP. 
The SIP software assumes you are using an account that is registered somewhere, until it creates you an account. 
With this, you don't need a real account anywhere.
